# Portfólio Profissional - Cesar Lacerda

Projeto desenvolvido para o **Laboratório 01** da disciplina de **Desenvolvimento e Integração de Aplicações Web (DIAW)** do curso de **Engenharia de Software** da **PUC Minas** (Prof. João Paulo Carneiro Aramuni).

## 📌 Descrição do Projeto
Website de portfólio profissional responsivo desenvolvido para apresentar minha trajetória acadêmica e profissional, habilidades técnicas (com foco em Java, Spring Boot e React), linha do tempo de projetos e canais de contato direto.

## 🚀 Link da Aplicação (Vercel)
🔗 [https://cesarlacerda.vercel.app](https://cesarlacerda.vercel.app) *(ou link temporário gerado pela Vercel)*

## 🛠️ Tecnologias e Bibliotecas Utilizadas
- **Front-end:** React.js (Vite)
- **Estilização:** Tailwind CSS
- **Ícones:** Lucide React
- **Envio de E-mails (Previsto S02):** EmailJS
- **Prototipação:** Figma
- **Hospedagem:** Vercel
